The idea.

One rover, one job.

Each model is built for a single task and its name says which. A scout never carries a tank, and a sprayer never tries to count bunches.

You set the block.

Draw the block on a phone, choose the task and the hour. The rover plans its own route, drives it without a pilot and docks when it is done.

Data, not footage.

Each pass returns counts, maps and flags you can set beside last week's pass over the same row. Nobody has to watch hours of video.
